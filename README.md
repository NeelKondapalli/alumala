# Alumala MVP

https://www.alumala.com/

Backend of the application.
# Running the backend

1. cd into backend directory (`cd backend`)
3. `pipenv run python manage.py runserver` to start the localhost server

# Running frontend

1. cd into frontend directory 
3. `npm run dev` to run the nextjs server


# URLs

To view the profiles/REST api, go to: http://127.0.0.1:8000/api/profile/
- Can manually interact with the database here.

To view the frontend, go to: http://localhost:3000/
